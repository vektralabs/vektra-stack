## Overview

Spec-level decision: the `no_relevant_context: bool` field in QueryResponse is defined in ARCH-056 and SC-B05, but has no corresponding functional requirement in requirements.md. This plan resolves the gap before component-core begins implementation. The field must be present in `QueryResponse` in vektra_shared before the QueryPipeline is implemented.

## Design Notes

**Recommended approach**: Add REQ-066 to requirements.md. The behavior ("when all retrieved chunks score below VEKTRA_MIN_RELEVANCE_SCORE, return a graceful response with no_relevant_context=true instead of an error") is user-facing and testable, making it a proper functional requirement. The alternative (architecture-only) would leave a gap in traceability.

This is a Wave 0 task: it must complete before component-core begins (Wave 3).
