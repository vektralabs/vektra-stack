## Overview

Small governance item: creates the CODEOWNERS file at the repository root to enable automatic PR review assignment on GitHub. Maps each component directory to its maintainer(s).

## Design Notes

Until actual maintainers are assigned, use the project lead GitHub username as placeholder for all paths. The file should be updated when additional contributors join.
