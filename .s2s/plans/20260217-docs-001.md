## Overview

Creates the docs/ directory structure following the Diataxis framework (tutorials, how-to guides, reference, explanation). Written for the Platform Operator persona. Phase 1 scope: getting started tutorial, configuration reference, error codes reference, and placeholder structure for guides. No static site generator configured in Phase 1 (DOCS-002 is separate and lower priority).

## Design Notes

- DOCS-002 (static site generator choice) is a separate backlog item and deferred. For now, docs are plain Markdown readable on GitHub.
- Content must be written for the Platform Operator: assumes Linux/Docker familiarity, prefers copy-paste examples over conceptual explanation.
- Configuration reference is the authoritative mapping of all 37 VEKTRA_* env vars (ARCH-060); it belongs in docs/reference/.
